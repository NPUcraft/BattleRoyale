## 证据边界

服务端探针中的 Player 接口记录器用于检查 API 参数、语言选择、实体可见性调用和计分板所有权；它不是登录的原生玩家客户端。原生实体或粒子 API 检查也不证明客户端最终视觉、真人右键、饮药、骑乘、完整多人对局或实际商店交易。

隔离环境使用生成地形样本与专用小测试世界，不包含完整远端 `Survival-Main`。通过有界地图校验不等于全图安全；测试中推进会话时钟不等于真人按墙上时间游玩。经济 API 余额持久化不等于购买、退款和跨插件事务的端到端覆盖。

此前 M1–M9、Paper 1.21.8 与 rc.3–rc.7 结果均属于历史证据。原始日志和旧文档按原名称保留在私有归档中；旧备份地址不会因产品改名而改变，不将机械替换后的历史路径当作有效证据。本文件不再重复旧版本的长篇部署日志或把其结论归属于 rc.8。
