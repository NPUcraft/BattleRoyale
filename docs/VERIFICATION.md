`scripts/paper-rc11.mjs` 从通过并正常停止的 rc.10 副本创建新实例，校验完整基准文件清单保持不变。应用已授权的 Survival-Main 有效范围 X/Z ±5000，以及本轮原生基础容器表和命名区域配置，保留依赖、经济和大厅数据。

首次完整通过：`.run/paper-rc11-1790845652263/results.json`。以下为该次结果：

- 400 个分散补给点全部落盘，未开启物品实体为 0；81 个明确预加载的平坦样本区块中，准备耗时 **2.682 秒**。这是已加载区块的调度基准，不是正式 Survival-Main 全图加载耗时。停止发生在真实异步请求发出后，没有迟到计划或重新覆盖领取文件。

- 菜单在房间服务尚未创建时不读取空服务；配置重载替换服务后旧菜单失效，新服务可正常投票。恢复仍使用保存的初始圈，不重新抽票。

发布工件按最终提交号重新构建，再执行该原生流程。最终 SHA-256、性能数值与正式部署状态以同版本 GitHub release 的 `release-verification.json` 为准；不提交 `.run/`、未脱敏配置、日志、数据库或凭据。

## 验证边界

方块、碰撞形状、物品、菜单、事件和持久化使用真实 Paper API；玩家输入、移动、滑翔标志与视图由接口记录器驱动。本轮未宣称真人客户端图形/物理、完整多人对局或约 16 GB Survival-Main 全图遍历已验收。

地面部署使用每 tick 2 ms 软预算，单次原生调用不能抢占；慢磁盘、未生成区块或安全落点不足仍可能增加耗时或减少点数。原有先持久认领后发放策略保持：两步之间崩溃可能少发一次，恢复不重发。区域品质仍是地表抽样近似。

CoinsEngine/NightCore 依赖版本保持不变，上游版本提示仍存在；本地通过不等于其官方宣布支持 Paper 26.2。
