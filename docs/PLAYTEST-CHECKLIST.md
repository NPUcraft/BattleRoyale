# BattleRoyale 全系统玩法测试剧本（多人大测试用）

> 适用版本：rc.42+　|　建议人数：10+　|　预计总时长：40~60 分钟
> 用法：按模块分工并行测试，每项后打勾；出现异常记录【现象 + 大概时间】，事后统一查日志。
> 管理命令均需 battleroyale.admin 权限。

---

## 0. 开测前自动自检（已由 AI 于 rc.42 完成一遍，开测时可复跑）
- [ ] 控制台：`battleroyale version` → 显示 rc.42 / recovery=OK
- [ ] 控制台：`battleroyale admin config validate` → 全部配置文件校验通过
- [ ] 控制台：`battleroyale admin map validate survival --deep` → 校验通过
- [ ] 控制台：`battleroyale debug economy` → active=coinsengine available=true | wealth: ready=true
- [ ] 控制台：`battleroyale debug storage` / `debug recovery` / `debug perf` → 无 failure

## 1. 大厅基础（每人都过一遍）
- [ ] 进服直接落在大厅世界，天气晴、正午、无掉虚空
- [ ] 侧边栏显示：在线人数 / 房间列表（solo duo squad 状态与人数）/ 财富榜 TOP5 + 全服合计 / 翻页提示
- [ ] 大厅建筑、保护（不能挖方块）、排行榜 TextDisplay 板渲染正常（Rating 总榜 TOP8）
- [ ] 右键荣誉榜旁讲台 → 打开个人档案（rating、击杀、胜场等）
- [ ] 手持指南针 → 房间选择菜单（分页、显示状态颜色）
- [ ] `/br shop` 外观商店打开、浏览分类、免费外观可领取；`/br cosmetics` 列出已拥有
- [ ] `/br profile` 个人档案菜单
- [ ] `/br leaderboard` 各分榜（rating/kill_score/wins/kills/assists/damage）
- [ ] `/br economy` 显示自己余额；管理员 `/br economy list` 显示全部账户（含离线）
- [ ] 聊天风格 / Tab 补全正常

## 2. 金币与财富榜（今天新功能，重点）
- [ ] 大厅侧边栏财富榜出现自己名字（余额>0 时）；0 余额号不上榜
- [ ] `/br debug item coin_100`、`coin_1000` 领取，绿宝石贴图、有光效、名字/lore 正确
- [ ] 大厅**对着地面**左键和右键各用一次 → 两次都 +100 入账（验证 rc.41 修复）
- [ ] 对着箱子等方块用金币 → 金币优先兑换，箱子不被打开
- [ ] 侧边栏财富榜排名/合计在 ~30 秒内更新
- [ ] 战斗中用金币同样可入账

## 3. 入房与开局
- [ ] `/br join solo` 入房：侧边栏切房间视角（人数、倒计时）、`/br vote` 开局区域投票
- [ ] solo 房 4 人起自动倒计时；人数不足 60 秒后不开始（或管理员 `/br debug start solo` 直接开）
- [ ] 开局广播队伍分配；`/br team` 查看队伍（duo/squad 验证分队）
- [ ] 跳伞：登机 → 走出平台下落 → 落地无摔伤、无卡墙；`min-distance 64` 出生点间隔够远
- [ ] 出生保护 60 秒：PVP 无效、计时结束有提示

## 4. 物资系统（核心，分人跑图验证）
- [ ] 初始地面补给箱：分布均匀、底层表 ground-early（皮革/铜/石头为主，无铁盾钻石）
- [ ] **人数缩放**：10 人局看服务器日志出现 `Initial ground loot scaled x1.6`，箱子数明显比 4 人局多（对照 debug loot 的 ground-points）
- [ ] 第二/三环补给（黄箱 ground-mid 出铁、红箱 ground-late 出钻石档）在对应阶段刷新
- [ ] 稀有度颜色：黄箱/红箱/特殊道具的粒子颜色区分正常
- [ ] 地图原生箱子（native-basic 低配表）与 built 区域（region-built 表）正常
- [ ] 空投：每个缩圈阶段 1 个，四轮内容递增（airdrop-1~4），保底一件附魔装备
- [ ] 空投有全局广播 + 光柱标记 + 20 秒下落 + 只能开一次
- [ ] 信号枪：使用后 20 秒空投落到自己头顶；连打有"调度正忙"提示
- [ ] 野怪掉落（mob-loot 35%）与马匹（16 匹上限、可骑）
- [ ] 药水五类（隐身/防火/治疗/剧毒/伤害）饮用与喷溅均有效

## 5. 战斗与道具
- [ ] 近战：剑/斧/矛/重锤/三叉戟攻击距离与伤害正常；盾牌格挡
- [ ] 远程：弓/弩/光灵箭；药水箭（迟缓/飘浮）命中生效
- [ ] 投掷火把：抛射点燃、命中实体着火
- [ ] 击退棒：只击退不伤人
- [ ] 疾风之履：穿上有 Speed I，脱下 ~1 秒后消失
- [ ] 神秘食物：15 buff 全上 + 凋零吼声全服可见 + 对应时长后死亡；最终圈 15 秒版
- [ ] 战斗烟花可发射

## 6. 缩圈与区域
- [ ] 边界墙可视化 + 越界阻挡；圈外伤害脉冲（伤害数字/反馈颜色随阶段）
- [ ] 缩圈阶段推进（stage 推进有公告）；空投与补给刷新跟随阶段
- [ ] 最后一圈：神秘食物 15 秒诅咒版生效

## 7. 死亡、经济与结算（今天新功能，重点）
- [ ] 死亡生成死亡物资箱（含背包全部物品+金币道具），全服死亡公告
- [ ] 观战自动进入；`/br spectate <房间>` 外部观战
- [ ] **击杀奖励 +200**：击杀者立刻收到 "+200 金币（击杀奖励）· 余额 xxx" + 音效
- [ ] zone/自杀/神秘食物死 **不** 发击杀奖励
- [ ] 金币可从死亡盒子里被敌人搜走并使用
- [ ] 打完一整局（不吃鸡也行，存活到终结）→ 前三名队伍每人 +1000/+500/+300，消息含名次
- [ ] 断线玩家在结算时：重连后余额里有名次奖金（离线补发）
- [ ] 管理员 `/br debug end solo` 提前结束 → **无**结算奖励（设计如此）
- [ ] 结算展示：胜者标题+烟花+全服庆祝；倒计时后自动回大厅
- [ ] 回大厅后原始物品恢复、等级恢复；可再次加入下一局
- [ ] `/br leave` 在结算阶段提前返回大厅正常

## 8. 断线与重连（压测重点，安排 1~2 人专门测）
- [ ] 比赛中故意断线 → 离线身体留在原地可被击杀
- [ ] 重连窗口内回来 → 状态恢复（位置/血量/物品）
- [ ] 超时未回 → 确认死亡、掉落死亡箱
- [ ] 断线期间被击杀 → 击杀者照常拿 +200
- [ ] 大厅断线重连无异常

## 9. 压测专项（10+ 人同时）
- [ ] 10+ 人同时入 solo 房：准备阶段（玩家数据/地图/出生点）无卡死
- [ ] 跳伞 10+ 人同时落地：无回弹/卡区块
- [ ] 全员捡箱、同时开箱：物资不重复、不消失
- [ ] 多人同时召唤信号枪：调度排队正常，无重复空投同一坐标
- [ ] 团灭式互杀：连续击杀奖励无丢单（对账 `/br economy list` 合计）
- [ ] 结算时 10+ 人同时回大厅：物品恢复无错乱
- [ ] TPS 观察：控制台 `battleroyale debug perf`，ZONE_TICK/LOOT 计时无尖刺
- [ ] 服务器日志无 ERROR/WARN 堆栈（除已知 SignedVelocity 警告）

## 10. 管理链路（管理员操作）
- [ ] `/br debug loot <session>` / `zone` / `teams` / `deathboxes` / `offline` 诊断可读
- [ ] `/br economy reset` → 二次确认流程 → 60 秒窗口、备份文件生成于 plugins/BattleRoyale/economy-backups/、审计日志追加
- [ ] 比赛进行中执行 reset → 被拒绝
- [ ] `/br admin cosmetic grant/revoke <玩家> <外观>` 生效
- [ ] `/br reload` 热重载不影响进行中的比赛

## 11. 已知非问题（不用报）
- SignedVelocity 对 nightcore 旧版聊天事件的 WARN（上游插件警告）
- 地图未设置观战点提示（回退到安全区/世界出生点）
- 财富榜合计与 TOP5 之和不一致（合计含全部 15 个账户）
- CoinsEngine 标记隐藏的账户在 list 里带注释（财富榜已忽略该标记）

## 异常上报格式
`【模块】现象 + 精确到分的时间 + 当时在做什么`
例：【结算】13:20 击杀后没收到 200，当时我和 xx 对枪，他先死。
→ 事后由 AI 用 mcsm 拉对应时间点日志定位。
